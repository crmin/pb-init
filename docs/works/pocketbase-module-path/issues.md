# 이슈

## 2026-11-11 미푸시 커밋 리뷰

- P2 해결: 기존 Go 모듈에 `vendor/`가 있으면 `go list -m`이 자동 vendor 모드에서 버전 조회를 거부했다. 조회 명령에 `-mod=readonly`를 지정해 단일 모듈과 Go workspace에서 해결했다.
- P2 해결: 새 경로에서 빈 HTTP 404/410 또는 파일 프록시의 메타데이터 부재가 발생할 때 GitHub 경로를 재조회한다. 403/503 응답 본문에 버전 부재 문구가 있어도 원래 오류를 전달하는 것을 확인했다.

## 기존 프로젝트 경로 전환

- 기존 프로젝트에서 새 경로를 선택할 때는 사용자 Go 파일과 마이그레이션의 import도 바꿔야 한다. README에 기존 경로 버전 지정과 수동 전환 방법을 기록했다.
